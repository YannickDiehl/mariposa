# Number of observations of a linear_regression model

Unweighted: the number of complete cases. Weighted: the unrounded sum of
the frequency weights of the complete cases - SPSS's N (the summary
shows it rounded).

## Usage

``` r
# S3 method for class 'linear_regression'
nobs(object, ...)
```

## Arguments

- object:

  A `linear_regression` result (ungrouped, listwise).

- ...:

  Not used.

## Value

A single number.
